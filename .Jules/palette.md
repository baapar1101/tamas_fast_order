## 2024-10-24 - [Add ARIA labels to icon-only buttons]\n**Learning:** The frontend makes frequent use of icon-only buttons (like ThemeToggle, Cart, and Wishlist), some of which only specify a `title` without an explicit `aria-label` attribute, limiting screen reader accessibility.\n**Action:** When implementing new icon-only buttons or reviewing existing ones in the tamas-fast-order project, proactively ensure `aria-label` is populated using the Farsi equivalent text if it is omitted.
