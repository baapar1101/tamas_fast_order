# بایگانی پنل مدیریت قدیمی

این پوشه نسخهٔ تاریخی برنامهٔ قدیمی تماس مارکت است. پنل مدیریت قدیمی در `index.html` و `Code.gs` قرار داشت و همراه با فایل‌های HTML، CSS، اسکریپت‌ها، تصاویر و نسخهٔ قدیمی کاتالوگ نگهداری شده است. این فایل‌ها بخشی از برنامهٔ اجرایی فعلی نیستند و نباید روی سرور به‌عنوان برنامه یا فایل عمومی منتشر شوند.

- `index.html` و `Code.gs`: رابط و منطق قدیمی Google Apps Script، شامل پنل مدیریت.
- `catalog_backup.json` و `tamas fast order.xlsx`: داده‌های تاریخی؛ مرجع قیمت، موجودی یا کد محصولات فعلی نیستند.
- `migration/import-legacy.ts`: اسکریپت مهاجرت قدیمی، صرفاً برای مطالعه. دستور اجرایی آن از بسته‌های پروژه حذف شده است.
- `graphify-out/`: نمودارها و خروجی‌های تحلیل همان نسخهٔ قدیمی.

پنل مدیریت فعال در `apps/web/src/admin/` و API فعال در `apps/api/src/` هستند. دادهٔ محصولات فقط از سایت و API فعلی بارگذاری می‌شود؛ هیچ fallback اجرایی به این بایگانی وجود ندارد.
