# tamasmarket — Design System

*تماس مارکت | فروشگاه دیجیتال* — Iranian wholesale (omdeh) webstore for mobile accessories.

## Product Overview

Tamas Market is an Iranian B2B/wholesale fast-order webstore for mobile accessories — phone cases, chargers, cables, glass protectors, earphones — rebuilt on Node.js + PostgreSQL + React with two-way Google Sheets sync. Two primary surfaces:

1. **Storefront (light)** — fast wholesale ordering: category rails, product cards, `قیمت فروش` from the client's real price lists, pill add-to-order CTA, teal promo strip.
2. **Dark ops admin (dark)** — slate-ink dashboard: order-status chips (success/warning/danger), product inventory table, emerald/cyan accents.

Everything in this package is **measured** from the codebase and the client's catalog bundle — nothing is invented. Canvas `#f5f5f7`, surface `#ffffff`, accent teal `#08798f`, deep `#00596b`, Vazirmatn FD 400–800, 8px grid, 0.2s `cubic-bezier(0.2,0.8,0.2,1)` motion. Product lines are BOROFONE / HIMI / YESIDO / VENDENS with real SKUs and prices from `context/catalog-data.json`.

## Reuse / review workflow

1. `@import` / paste `colors_and_type.css` first (fonts + tokens).
2. Reference tokens via `var(--tamas-*)`, RTL-first microcopy, LTR `unicode-bidi: isolate` for prices/SKUs.
3. Bind real art from `logos/`, `imagery/products/catalog/`, `imagery/banners/` — never hot-link external hosts.
4. Only use products/prices from `context/catalog-data.json` (never samples).
5. Inspect: open `preview/` cards, run `ui_kits/app/index.html`, then reference `preview/*.html` artifacts.
6. Follow `DESIGN.md` posture rules (pill primary buttons, promo-strip gradient, dark ink admin shell).

## Regenerating derived tokens

Run `od brand finalize anker-535220` to re-derive `system/` + `kit*.html` + `index.html` from `brand.json`.

> Note: `seed.json`/`theme.json`/`tokens.*.json`/`variables*.css` carry the **measured** state colors (`#34c759`, `#ff9500`, `#ff3b30`, and dark-mode `#10b981`/`#f59e0b`/`#fb7185`). `finalize` regenerates the palette from `brand.json` but normalizes colors to the 7 core roles; the state-family values are re-applied manually after each finalize.

## Caveats

- The design system is derived from the **real catalogs** (`D:\tamas_fast_order\catalogs`): BOROFONE/HIMI/YESIDO/VENDENS lines. Product names, SKUs (BX/BJ/BR/BO/BH/BG/MOTION/XOOM/…), and `قیمت فروش` values in previews and the UI kit come from `context/catalog-data.json` — real extractions, not samples. Native-sheet prices are preserved verbatim (no invented pricing). Price units: BOROFONE/YESIDO/VENDENS sheets are thousand-Toman, HIMI is Rial — keep the unit in captions.
- Product photos in `imagery/products/catalog/` are **category-level** pairing (CABL/CHARG/SPEAKER…); never claim exact per-photo model identity.
- Two original catalog jpgs (`img_0d1a7906c30a.jpg`, `img_0b26e1f26033.jpg`) have unknown dimensions — re-encode before using as sized content. Newly ported `imagery/products/catalog/` files were re-encoded to progressive JPEG (≈900px) for web-safe embedding.
- Old `.xls` workbook (`OTHER.xls`) was not parsed (no `xlrd`); all `.xlsx` sheets were.
