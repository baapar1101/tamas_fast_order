# Tamas Fast Order

فروشگاه تماس مارکت شامل API، وب‌اپ و بسته‌های مشترک است. برای راه‌اندازی و معماری، [راهنمای پروژه](docs/project-guide.md) را بخوانید.

**استقرار تولید از طریق aaPanel مدیریت می‌شود.** API به‌عنوان پروژهٔ Node.js و فرانت به‌عنوان سایتِ سروکنندهٔ فایل‌های ساخته‌شده ثبت شده‌اند؛ پیش از هر تغییر یا راه‌اندازی مجدد، [راهنمای استقرار aaPanel](docs/operations/aapanel-deployment.md) را بخوانید. سرویس تولید را یک نصب مستقلِ PM2 یا systemd فرض نکنید.

| مسیر | محتوا |
|---|---|
| `apps/api/` | API، دیتابیس و سرویس‌های همگام‌سازی |
| `apps/web/` | فروشگاه و پنل مدیریت |
| `packages/` | بسته‌های مشترک |
| `payment/` و `chatbot/` | زیرپروژه‌های مستقل |
| `docs/` | راهنماها و اسناد Markdown پروژه؛ [فهرست اسناد](docs/README.md) |
| `references/` | نمونه‌ها و داده‌های مرجع خارجی؛ [فهرست مرجع‌ها](references/README.md) |
| `scripts/` | ابزارهای اجرایی مخزن |
| `archify-out/` و `graphify-out/` | خروجی ابزارهای نمودار و بررسی بصری |

فایل‌های تنظیمات و کلیدهای محلی باید در مسیرهای تعیین‌شدهٔ برنامه بمانند و در Git ثبت نشوند. مستندات مهندسی ابزارها داخل `.agents/` نگهداری می‌شوند.
