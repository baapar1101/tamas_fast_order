## 2026-10-26 - Refactored O(N*M) Array Find Lookup to O(1) Map Lookup\n**Learning:** In fastify route handlers where arrays of data are mapped to DTOs, using `Array.prototype.find()` inside the `.map()` callback creates an O(N*M) performance bottleneck, especially as the number of rows or related entities grows. This was observed in `apps/api/src/routes/admin/orders.ts` for payment instructions lookup.\n**Action:** Always precompute a `Map` keyed by the relational identifier (e.g., `orderId`) before entering the `.map()` loop. To precisely preserve the original `.find()` behavior of returning the *first* match, wrap the `Map.set` operation in an `if (!map.has(key))` condition.
