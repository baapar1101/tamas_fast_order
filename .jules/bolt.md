
## 2024-05-18 - React.memo with Unstable Global Selectors
**Learning:** In React applications using Zustand (or Redux) where lists of items subscribe to a global array (like a shopping cart `lines` array), using standard `React.memo` is completely ineffective because the global array reference changes on every single cart action. This causes *every* item component on the page to re-render, creating O(N) rendering performance issues when the user changes a quantity. Furthermore, omitting callbacks from a custom `arePropsEqual` implementation creates high-risk stale closures, where child components hold outdated state contexts from old renders.
**Action:** Always provide a custom `arePropsEqual` function to `React.memo` that explicitly checks the sub-properties that actually affect the specific item component. Check callbacks to ensure safety. Alternatively, use `useShallow` from Zustand to select only the primitive value needed by the component inside the component itself.
