## 2024-06-25 - [Prevent O(N) re-renders in mapped React components caused by global array reference changes]
**Learning:** Avoid passing frequently updated global state arrays (like `cartLines` from Zustand) directly as props to memoized child components mapped in lists. When a single element in the array is added or updated, the reference of the entire array changes. This causes all components in the list to re-render because `React.memo` uses shallow equality by default.
**Action:** Provide a custom `propsAreEqual` function to `React.memo` that performs a deep comparison specifically on the elements of the array that are relevant to that specific child component (e.g. comparing the cart line quantity for that product across warehouses). This ensures that only the affected components are re-rendered.
