## 2024-11-21 - Optimize ProductCard re-renders
**Learning:** In a codebase using a global state manager (like Zustand) that maps a frequently updated array to child components (e.g., `cartLines` to `ProductCard`), passing the global array directly as a prop breaks `React.memo`'s default shallow comparison. Any change in the global array (like adding an unrelated item) updates its reference, causing widespread unnecessary re-renders of all mapped child components.
**Action:** When a mapped component needs access to a global array for finding its own items, always provide a custom `propsAreEqual` function to the component's `memo`. Filter the array to extract only the items relevant to that specific component and perform a deep comparison on them. This ensures the component only re-renders when *its specific data* within the global array changes.
